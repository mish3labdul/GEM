**WORKING ASSETS — PRODUCTION-MASTER ACCEPTANCE PENDING.** Preserve the GEM mark and source bytes.

- `layout-derivatives/`: existing layout-fitted derivatives, separate from supplied artwork.

The library/package version is not proof of an artwork version.

The original source descriptions and checksums remain in [the archived asset package](../archive/baseline-v3.0/GEM_Brand_Assets_v1.0/README.md).
