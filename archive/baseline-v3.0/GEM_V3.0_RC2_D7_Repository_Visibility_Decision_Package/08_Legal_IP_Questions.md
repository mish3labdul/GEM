# 08 · Questions for Legal/IP Counsel (8)

Context: both GEM repositories are public; VAL-03, VAL-04, VAL-06 are Not started and VAL-05 is In progress (`05`). Facts for each question are in `03` (existing exposure) and `04` (what a push would add). Answers are for the Brand Owner's D7 decision; this package does not answer them.

1. **Continued public hosting.** Is continued public hosting of the current GEM source and editable brand material (editable decks and templates, vector logo masters, tokens) acceptable while the trademark (VAL-03) and ownership (VAL-04) gates remain open?
2. **Font binaries.** Are the font binaries currently in the repository, and their distribution through a public GitHub repository, confirmed as permitted? This includes the 3 baseline Regular files and the Bold and variable builds reachable through open PR #10.
3. **Visual assets.** Are all photography, mockup, AI-generated and third-party visual assets authorized for distribution in a public source repository? In particular the 15 AI-generated concept images (VAL-06), and whether any image contains a third-party mark or property.
4. **Logo masters and implementation assets.** Is public disclosure of logo masters, vectors and implementation assets acceptable from an IP-protection perspective, before master acceptance (VAL-02)?
5. **ODI01-R1 audit and QA material.** Is the ODI01-R1 audit, QA and governance material (draft commentary, validation gaps, owner decisions, Git evidence with local paths) appropriate for public disclosure, and should this D7 package itself be kept off any pushed branch?
6. **Private until gates close.** Should the repository, or only new candidate work, be private until VAL-03, VAL-04, VAL-05 and VAL-06 close?
7. **Prior disclosure.** If prior public disclosure has already occurred (`03`), is any remediation required, for example for the open pull-request refs, the second public repository, or the history copies of removed files?
8. **Branch-only publication before AC20.** Is branch-only publication of unapproved candidate material acceptable before AC20 is authorized?
