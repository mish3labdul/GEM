# 04 · Visual direction (proposed)

**Idea.** The site behaves like the brand idea: *every arrival, precisely composed*. The first thing a visitor sees is the mark arriving on an Ink field — the ring draws, the spark appears, the quarter fills — and then everything else stays still and exact. Boldness is spent once, on that moment; every other section is quiet, ruled and specific.

| Area | Decision | Source |
|---|---|---|
| Palette | Ink #12171D, Beige #BCACA7, Black #020202 (hover/pressed), White #FFFFFF. Surfaces: White canvas, Ink signature (hero, partners, footer), Beige selected (who we work with). Pairings used: White/Ink 18.0:1, Beige/Ink 8.2:1, Ink/Beige 8.2:1. Never Beige on White for text. No gold, gradients, shadows or fifth colour. | Part A 32–33; Part B 6–7 |
| Type | Jost 400 for headings, tagline, eyebrow, labels; Inter 400 for all reading text. One weight only (500 pending accepted file). Body 16/26 (18/30 for leads). h1 48/56 (40/48 compact), h2 32/40, h3 24/32. Tagline Jost caps 14/20, .18em, one line. Eyebrow caps .16em. Body never tracked. Measure ≤ 70ch. | Part A 34–36; Part B 9–11 |
| Layout | Bands 0/480/720/1024/1440; 4/4/8/12/12 columns; gutters 16/16/24/24/24; margins 16/24/32/48/48; max 1080, 1280 at 1440+. Off-centre balance: copy on columns 1–6/7, open field opposite. | Part A 40; Part B 14–15 |
| Shape | Radius 0 for images and panels, 4px for controls. Hairlines 1px; 2px only for error, focus, emphasis. No elevation. | Part B 8 |
| Graphic language | One oversized Beige ring, cropped by the frame, on the Ink partners section — desktop only, never behind text. The spark appears only inside the mark. | Part A 41–44 |
| Imagery | Material and object studies, single-source light, warm neutral, subject on a third. Every image captioned as a concept or reference study. No people, no generic hotel stock, no text over images. | Part A 47–50; Part B 28 |
| Status | Pending items use the dashed status label with a word ("In development", "Being defined"); information and error states use solid borders with words. Meaning is never carried by colour. | Part B 2, 7, 19 |
| Motion | One reveal on load (1.5 s, ease-out, once). Hover: colour only, 150 ms. Menu: opacity 200 ms. Form result: opacity 180 ms. No parallax, scroll effects, loops or bounce. Reduced motion: everything 0 ms, mark shown at rest. | Part A 51; Part B 17 |
| Components | Header with disclosure navigation below 1024px; buttons (primary, secondary, on-signature); text link; status label; figure with caption; ruled lists; form fields with errors above the control and an error summary. | Part B 22–25 |

**Self-review against generic defaults.** Checked against stock "premium" patterns: no full-bleed photo hero with overlaid headline (Part A forbids text over busy images); no rounded card kit or shadows; numbered markers used only where content is a real sequence (label order, release steps); caps limited to the tagline, one eyebrow and small labels the brand defines. The one risk noted: ruled lists and zero radius can read as a generic editorial layout. They are kept because Part B mandates them, and are offset by the mark reveal and the Ink/Beige surfaces, which are specific to GEM.
