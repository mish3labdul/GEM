## Current revision test record

Eight delivery DOCX files each render to one A4 page. English, Arabic and bilingual explicit-break two-/three-page fixtures and automatic-flow two-/three-page fixtures were rendered. English natural-flow examples use 8 and 16 added paragraphs for two/three pages. The original 20-paragraph stress example now uses four pages; that is expected repagination after correcting leading and measure, not a defect to conceal. Long fields, signatures, mixed technical IDs and contextual numeral specimens were included.

Every current template/specification/fixture page was visually inspected in `review_contact_sheets/`, with detailed template-page inspection. Final portfolio and grayscale pages were reviewed separately. Exact font embedding, glyph coverage, SVG bytes, colour values, A4 dimensions, searchable text and tag/language structure are checked in the current structural/review JSON records. Microsoft Word for Mac opened the revised English, Arabic and bilingual first-page files without repair prompts; each displayed Page 1 of 1. Logo placement, shaping, mixed IDs, subject/body/signature and sequential bilingual hierarchy were visually reviewed. No edit/save test was repeated on revised Arabic or bilingual files. The prior Arabic edit/reopen test copy and report are in `pre_review_evidence/` and must not be used as R1 approval.

No physical printing, native Arabic linguistic review, assistive technology, cross-platform Word full matrix, supplier colour/prepress or independent approval test was performed. Missing required fonts or corrupted glyphs must fail export; silent substitution is not accepted.
