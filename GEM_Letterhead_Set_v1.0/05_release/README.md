# GEM™ Branded Letterhead Set v1.0

**WORKING APPLICATION / PENDING VALIDATION · Review revision R1**

A controlled RC2 application for A4 business correspondence. The approval register remains highest authority. Production-master acceptance, native localization, accessibility evidence, prepress/physical proof and final owner authorization remain open.

## Use

1. Open the desired file in `01_templates/` (the same delivery files are gathered in `05_release/`). English, Arabic and bilingual First Page documents automatically use quieter continuation headers on later pages. Executive is the formal English variant; Minimal is the English low-ink variant.
2. Save a new letter copy. Replace SAMPLE CONTENT and all name, date, reference, address/contact and signature placeholders. Arabic strings are unapproved working examples. Do not send sample text.
3. Update references in the continuation header and contact values in both first/default footer variants. Live PAGE/NUMPAGES fields update with document pagination.
4. Preserve Inter/Jost/Noto Sans Arabic, paragraph direction and exact leading. Only the in-use Regular 400 font instances are embedded and supplied with OFL references. If fonts are unavailable or glyph support fails, stop and report; do not substitute silently.
5. Export the actual completed letter to tagged PDF and review every page. The supplied eight-page Digital and Print PDFs are proof portfolios showing all variants, not a single letter to email.

`GEM_Letterhead_Print.pdf` is an A4 vector candidate for supplier review, not an authorized commercial print master. CMYK/profile/PDF-X/stock/GSM/tolerances and physical proof are unresolved. Printing at 100% and office-safe layout do not close Part C release gates.
